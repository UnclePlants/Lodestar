# AoE Line Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a fourth Area-of-Effect shape — a thin, multi-point line (polyline) — for spells like Wall of Fire / Wind Wall / Lightning Bolt, matching the existing circle/square/cone AoE tool's look and persistence model.

**Architecture:** Everything lives in the existing three files (`app.js`, `index.html`, `styles.css` needs no changes — the icon button reuses the `.icon-segmented svg` rule already in place). The line reuses the app's two existing multi-point/multi-shape patterns instead of inventing new ones: (1) the fog-polygon draft loop (`drawingRoom`, click-to-add-point, Enter/dbl-click-to-finish, Ctrl+Z/Backspace/Escape while drafting) for placing the line, and (2) the existing `state.aoeMarkers` persistence/sync/select/delete pipeline for storing and showing it once placed.

**Tech Stack:** Vanilla JS (no framework, no build step, no bundler), Canvas 2D, static HTML/CSS. No test runner exists in this repo.

## Global Constraints

- No automated test framework exists in this project (no `package.json`, no test files). Every task's "test" step is: (a) `node --check app.js` as a fast syntax gate, and (b) a manual browser verification (open `index.html` directly — the app works from `file://`, no server needed).
- Follow the existing single-large-file convention — do not split `app.js` into modules.
- Match the existing AoE visual language exactly: translucent fill/body at `globalAlpha = 0.28`, solid outline/spine at `globalAlpha = 0.9`, selected-marker dashed highlight in `#b1c301`.
- No grid-snap and no live cursor-rubber-band for the line tool — matches existing AoE marker placement (unsnapped) and existing fog-polygon drafting (no live segment preview), per the approved design spec.
- No drag-to-move for placed line markers — circle/square/cone markers can't be dragged either; stay consistent.
- Full details and rationale: `docs/superpowers/specs/2026-08-06-aoe-line-design.md`.

```js
// Stroke a polyline as a translucent thick body plus a thin solid centerline —
// the line-shape equivalent of the fill+outline look used by circle/square/cone.
function strokeAoeLine(points, widthPx, color) {
  ctx.beginPath();
  points.forEach((p, i) => (i === 0 ? ctx.moveTo(p.x, p.y) : ctx.lineTo(p.x, p.y)));
  ctx.lineJoin = "round";
  ctx.lineCap = "round";
  ctx.globalAlpha = 0.28;
  ctx.lineWidth = widthPx;
  ctx.strokeStyle = color;
  ctx.stroke();
  ctx.globalAlpha = 0.9;
  ctx.lineWidth = 2 / (curK * curMs);
  ctx.stroke();
}
```

```js
// Shortest distance from point p to the segment a–b (native coords).
function distanceToSegment(p, a, b) {
  const dx = b.x - a.x;
  const dy = b.y - a.y;
  const lenSq = dx * dx + dy * dy;
  let t = lenSq ? ((p.x - a.x) * dx + (p.y - a.y) * dy) / lenSq : 0;
  t = Math.max(0, Math.min(1, t));
  return Math.hypot(p.x - (a.x + t * dx), p.y - (a.y + t * dy));
}

// Label-anchor point for a line marker: the centroid of its vertices.
function aoeLineCentroid(points) {
  const sum = points.reduce((acc, p) => ({ x: acc.x + p.x, y: acc.y + p.y }), { x: 0, y: 0 });
  return { x: sum.x / points.length, y: sum.y / points.length };
}
```
